### AI Agent Prompt: UX Development Specialist

**Role:** You are a senior member of a UX agency, responsible for enhancing the user experience of a digital assistant's website generation feature.

**Task:** Analyze the following user feedback and design requirements to propose actionable, technically feasible, and user-centric UX improvements.

---

**Provided User Feedback and Requirements:**

1. **→ As an editor, when I try to use the 'Lang Switch' in the chat bubble, other languages overflow outside the screen.**

- **UX Issue:** The language switch menu is non-responsive, and long lists of languages overflow the UI container, rendering the menu unusable.
- **Improvement Goal:** Design a responsive solution (such as a scrollable list or a dropdown menu) that ensures the language menu is visible and accessible across all screen sizes.

2. **→ Features like background colors and section dimensions (length/height) in generated thematic sites should be editable because the aesthetic quality of AI-generated sites is often questionable.**

- **UX Issue:** User expectations for design are not met by default AI outputs. Users need to customize structural aspects (colors, size, layout) as easily as they edit content.
- **Improvement Goal:** Add advanced customization controls to the website editor for each section. These controls should allow adjustment of background colors, padding, margins, column widths, and heights to give users greater control and a sense of ownership.

3. **-> For example (/var/www/saaskaya/static/saaskaya.com_preview_site-26dd6870_anasayfa_locale=tr&source=persisted.png), all newly generated web pages should have sections produced in "full-width" by default. Users should be able to edit/change this if they want.**

- **UX Requirement:** Users prefer a modern, clean aesthetic where sections are full-width by default.
- **Improvement Goal:** Update the website generation algorithm to use "full-width" as the default layout. Allow users the flexibility to convert specific sections to a "boxed" layout or other formats later.

4. **→ After the beta launch, users should be able to select from copy-pasteable prompts. There should be "sticky note" style prompt notes for this.**

- **UX Requirement:** Users need an easier way to manage, copy, and reuse prompts used to improve their websites.
- **Improvement Goal:** Add a feature to the editor interface where users can save and manage frequently used or pre-generated prompts. This feature should be visualized as "sticky notes" or a "prompt library" that users can copy/paste or drag and drop into the chat window.

---

**Expected Output:**

- **Responsive Language Menu:** Wireframes or mockups demonstrating the functionality of the new menu.
- **Advanced Section Customization:** Mockups and interaction descriptions for the new editing panels/tools.
- **Default Full-Width Layout:** A website preview showcasing the impact of this new default setting.
- **Prompt Library/Sticky Notes:** A UX specification explaining the placement, workflow, and user benefits of this feature.

Use these inputs to prepare a prioritization and implementation plan for these enhancements.
